# 📱 InfoCell

Landing page responsiva da InfoCell, negócio local de assistência técnica e soluções de tecnologia. O site apresenta serviços para celulares e notebooks, informações sobre a empresa e formas de contato, com navegação pensada para funcionar bem em celulares.

🌐 **Acesse a landing page publicada:** [devpedrogo.github.io/Info-Cell](https://devpedrogo.github.io/Info-Cell/)

## ✨ Sobre o projeto

A página apresenta a InfoCell e seus serviços de assistência técnica para celulares e notebooks, além de acessórios, impressão e xerox. O layout prioriza a experiência em dispositivos móveis e facilita o acesso aos canais de contato.

## 🧰 Tecnologias utilizadas

- **HTML5** — estrutura e conteúdo da página.
- **CSS3** — identidade visual, layout responsivo e animações.
- **JavaScript** — menu mobile, destaque da seção atual e efeitos ao rolar a página.
- **Font Awesome** — ícones.
- **Google Fonts** — fontes Kanit e DM Sans.

O projeto não utiliza frameworks ou ferramentas de build: os arquivos estáticos são carregados diretamente pelo navegador.

## 🚀 Como executar localmente

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` no navegador ou sirva a pasta do projeto com qualquer servidor HTTP estático.

> 💡 Font Awesome e Google Fonts são carregados de serviços externos. É necessária uma conexão com a internet para exibir esses recursos.
